# mailrelay docs

The [main README](../README.md) covers the quick start, rules and payload templates. These pages cover running mailrelay for real.

- [Self-hosting](self-hosting.md): choosing a host, DNS, Docker and binary installs, backups and upgrades
- [Reverse proxy and login](reverse-proxy.md): Caddy, nginx and Traefik, plus OIDC login for the web UI
- [Webhook recipes](webhooks.md): securing your receivers and templates for ntfy, Discord, Slack, Home Assistant and n8n
- [Troubleshooting](troubleshooting.md): what each status means and how to find out why mail went missing
- [Prometheus metrics](prometheus.md) and the [Grafana dashboard](grafana-dashboard.json)
